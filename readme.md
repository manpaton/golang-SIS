# SIS: Password Checker

Маленькое Go-приложение, которое проверяет и анализирует пароли.
Все данные хранятся в памяти.

## Запуск

    go run .

## Тесты

    go test ./...

## Правила пароля

- длина от 8 до 30 символов
- только латиница, цифры и символы
- без пробелов
- минимум одна заглавная буква
- минимум один символ (например `!`)

## Жизненный цикл задачи

    pending -> processing -> completed

- `pending`: задача создана, ещё не обработана
- `processing`: задача обрабатывается прямо сейчас
- `completed`: обработка завершена, результат сохранён

Допустимые переходы:

- `pending` -> `processing` (при вызове Process)
- `processing` -> `completed` (обработка прошла успешно)
- `processing` -> `pending` (если обработка вернула ошибку)

Всё остальное недопустимо. Например, повторная обработка
`completed` задачи вернёт ошибку `ErrInvalidTransition`.

## Результат обработки

- длина пароля
- есть ли цифра
- есть ли заглавная буква
- есть ли символ
