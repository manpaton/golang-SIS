# SIS: Password Checker (CP2 - Concurrent Processing)

Маленькое Go-приложение для валидации и анализа паролей.
Во второй версии (CP2) добавлена многопоточная обработка задач (Worker Pool).

## Запуск
    go run .

## Тесты
    go test ./...
    go test -race ./...

## Архитектура Concurrency (Worker Pool)
Приложение использует паттерн Worker Pool для параллельной обработки задач:
- **Количество воркеров:** 2 горутины.
- **Очередь (Task Queue):** Буферизованный канал `chan int` вместимостью 10 задач.
- **Поведение при переполнении:** Если очередь заполнена (10 задач в канале + 2 в обработке), новые задачи не блокируют поток, а моментально отклоняются с ошибкой `ErrQueueFull` (Option A).
- **Синхронизация:** Доступ к in-memory хранилищу задач (`map`) защищен с помощью `sync.RWMutex`, что исключает состояние гонки (data races).

## Жизненный цикл задачи
    pending -> queued -> processing -> completed

- `pending`: задача создана, но ещё не отправлена в очередь.
- `queued`: задача успешно добавлена в канал и ожидает воркера.
- `processing`: воркер взял задачу и выполняет анализ.
- `completed`: анализ завершен, результат записан.

## Безопасная остановка (Graceful Shutdown)
При завершении работы вызывается метод `Stop()`. Он переводит флаг `stopped = true` (запрещая принимать новые задачи), закрывает канал очереди (`close`) и использует `sync.WaitGroup`, чтобы дождаться успешного завершения всех задач, которые уже были приняты в очередь.
